# JavaScript的了解
JavaScript常用于web2的开发中，常常与html,css等网页编程语言一起出现，一般作用于交互式网站
伴随着区块链技术的发展，Web3的人们并不满足于单独开发点对点账单的应用了，他们发现在区块链上同样可以像Web2一样部署许多Dapp，以及智能合约
智能合约，顾名思义，也是一种去中心化的产物；常见的智能合约有Defi，DEX等
而JavaScript与开发各类智能合约的Solidity语言相似，我们往往认为打好JavaScript的基础是有利于后面的Solidity语言学习的
# Const
Const：声明一个不能重新赋值的变量
例如：Const myname =  "b1nwen';
例如：Const hobbies = ["a","b","c"];
例如：Const book = {
          title:"XXX"
          author:"XX"
          year:2024
        };
# Console
console.log() 打印普通信息
console.error() 打印错误信息
console.warm() 打印警告信息
console.table() 打印数组对象

# 个人随笔
人们常说在这个ai时代，学习计算机是落后的，落伍的；但我并不这么认为，我发现大部分说ai时代，技术已经不是核心竞争力的有两类人
第一类人，属于资深的技术大咖，他们是出于对ai技术的了解而发出的感叹
第二类人，则属于普通人，他们并没有从事IT相关行业的经验，并且对于互联网的发展也并不了解，唯一的渠道就是抖音推送的信息
对于前者，我表达尊敬与敬佩，他们是ai时代下的利益损失者，我对他们的情感就像对三国演义中的老将廉颇一样，充满尊敬
对于后者，我表达深深的忧虑，因为他们其实并不了解ai，也并不了解IT行业，在我看来，他们是一群不得志者，只有通过贬低“技术”才能满足自己技不如人的幻想
这样的人是很可悲的，也是比较可恨的
而我想要做什么样的人？或者说我对未来如何看呢？
出人意料，我对未来充满信心，我当然知道ai技术的发展从客观上会取缔不少的技术岗位，让人类引以为傲的编程技术跌入谷底
但即使如此，我依旧很自信，因为我相信一个亘古不变的真理：工具会变，问题不会；答案会便宜，判断不会；代码会贬值，责任不会
