# 对函数的新知新解
1.将函数赋值变量  
例如:  
function add(x,y){  
         return(x+y);
         }  
调用函数方法：  
const myFun = add;  此处用“const”声明了用“myFun"存储了函数名"add"
console.log(myFun(2,3));  于是在这里变量“myFUn"便拥有了等同于函数add的调用  

2.当参数传  
例如：
function calculate(fn,a,b){  
         returnfn(a,b)
         }
调用函数的方法：
PS：此处其实也是一个实参代替形参的切实例子
console.log(calculate(add,5,3));  这里用“add”代替了“fn”，用“5”“3”分别替代了“a”与“b”

3.纯函数与不纯函数的划分
纯函数的性质：  
1.只依赖传入参数
2.不修改外部任何变量
3.不打印，不请求网络
总的来说，就是该函数的所有调度都“取法于内”

不纯的函数：
例如：  
let count = 0
function addCount(){
         count++;
         return count;
         }
此处的addCount函数调度，需要上面的"let count = 0"的调度，所以它属于“不纯”函数
